# Aethrix 
### BRL Trainees '26

> A list of members, profiles, and fun — built by students, for students.

Welcome to **Aethrix**, the official interactive profile directory and cryptographic chain explorer for the **Blockchain Research Lab (BRL) Trainees of 2026**! ✨

---

## 🚀 How to Add Yourself (5 Easy Steps)

### 1. Fork this repo
Click the **Fork** button at the top-right corner of this repository to create your own copy.

### 2. Create your member file
Go to the `members/` folder and create a new file named after your GitHub username:
```text
members/<your-github-username>.json
```
*Example:* `members/anirudhagarwal-dev.json`

### 3. Fill in your profile details
Open your JSON file and add your details in the following format:

```json
{
  "name": "Enter your name",
  "branch": "Enter your branch",
  "githubID": "Enter your GitHub username",
  "url": "Enter the URL of your GitHub profile",
  "about": "Enter a short bio about yourself"
}
```

### 4. Commit your changes
Commit the file with the following commit message format:
```bash
member: add <your-github-username>
```
*Example:* `member: add anirudhagarwal-dev`

### 5. Create a Pull Request
Submit a Pull Request from your fork to the `main` branch → Wait for reviewers → Merge 🎉

---

## 📜 Contribution Rules

- **Filename**: File name must exactly match your GitHub username in lowercase (`<username>.json`).
- **Valid Schema**: JSON schema should be valid (CI will check automatically).
- **Images**: Keep profile images/assets under 200 KB for fast loading.
- **Zero Secrets**: No secrets, private keys, or API keys allowed.
- **Respectful**: Keep bios professional, respectful, and PR titles clear.

---

## 💻 Tech Stack

- **Frontend**: HTML5, Vanilla CSS, JavaScript, [Three.js](https://threejs.org/) (3D WebGL Scene)
- **Hosting**: Vercel / GitHub Pages
- **CI/CD**: GitHub Actions (schema validation + manifest generation)
